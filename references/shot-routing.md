# 镜头分流与代理选型

根据镜头需要控制的信息选择白模模式和代理精度。以下为通用制作规则与示例。

## 适用规则

1. 多人物在同空间：用白模控制相对位置、距离、遮挡和视线。
2. 镜头有明确构图目标：用白模设计构图和摄影，即使没有复杂动作。
3. 复杂运镜加多人物：用白模协调人物调度和独立相机。
4. 普通对话：优先纯文字提示词，不额外制作白模；已有身份和场景参考仍可配合使用。
5. 简模和人形按信息需要选择，不整片统一用方块，也不整片统一用复杂人形。

普通对话遇到复杂调度、前后景关系或专门构图要求时，以具体空间和摄影需求为先。

## 可检查的选型例子

| 需求 | 选择 | 最低有用的表达 |
| --- | --- | --- |
| 高塔极俯视，一个小小的人站在塔边 | 构图白模 | 楼群与塔冠灰色体块；远处人可用占位；若起跳或俯冲姿态入镜则该人升B级 |
| 三人在一个房间前中后景互相遮挡，保持原位 | 站位＋构图白模 | 房间简模、可读头肩与朝向；不强迫增加走路和接触 |
| 长镜头穿过前景群体再揭示主角 | 混合白模 | 群体远处可简模，近景轮廓需人形；镜头路径和注视目标分开，记录揭示时机 |
| 抓腕拉人过窗 | 动作白模 | 窗和平台简模，两人关节人形和手腕、脚支点接触控制；背景不必升级 |
| 两个人普通正反打聊天 | 文字 | 台词、眼神、表演、景别与轴线说明，无需新白模 |
| 固定机位，门框构图中人物静止等待 | 构图白模 | 门框体块、人物轮廓、负空间和透视；固定相机和静止人物可以通过 |

## 交接原则

场景简模证明尺度、轮廓和空间；人形证明姿态和动作；接触控制证明抓握、支撑等因果；相机证明构图、遮挡与节奏。它们可在同镜混用。

最终外观仍由资产图控制，白模默认无声。固定构图输出可播放的定长持镜视频，无需为了让画面运动而虚构运镜或角色动作。
